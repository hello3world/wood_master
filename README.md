# Wood Master Workshop

Welcome to Wood Master Workshop - a beautifully crafted website for artisans who work with wood!

![Wood Master Workshop Demo](images/chrome_fp92JKogBM.gif)

## About This Project

This website was created using AI for a friend who works with wood. It showcases woodworking craftsmanship, gallery of handmade items, stock materials, and delivery services.

## Main Functionalities

- **Homepage**: Introduction to the workshop and featured projects
- **Gallery**: Showcase of completed woodworking projects with detailed images
- **Stock**: Available wood materials and supplies for purchase
- **Delivery**: Information about shipping and delivery services
- **Privacy Policy**: Legal information and privacy guidelines

## Live Demo

Check out the live website: [Wood Master Workshop Demo](https://hello3world.github.io/wood_master/index.html)

## Technology Stack

- HTML5
- CSS3 (with responsive design)
- JavaScript (Vanilla)
- Static hosting compatible

## Getting Started

To view the website locally:
1. Clone this repository
2. Open `index.html` in your browser
3. Or use a local server:
   ```bash
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`
